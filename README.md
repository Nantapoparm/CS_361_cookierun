# Project Name
ระบบเบิกค่าตอบแทนการสอน

## Project Vision
ระบบกลางที่ช่วยจัดการตรวจสอบการเบิกค่าตอบแทนการสอนและปรับเปลี่ยนข้อมูลได้ยืดหยุ่น เพื่อลดข้อผิดพลาด
## Primary User
อาจารย์ / พี่ TA 
## Problem
กรณีข้อมูลไม่ถูกต้อง จะต้องเอากลับไปแก้แล้วให้อาจารย์เซ็นใหม่อีกที ทำให้เสียเวลา
## V1 Goal
สร้าง solution ที่ช่วยแก้ปัญหาการขอเบิกเงินและติดตามสถานะการเบิกของ ของ อาจารย์ และ TA
## V1 In scope
- ระบบตรวจสอบความถูกต้อง
- ระบบแก้ไขเอกสาร
- ระบบติดตามสถานะ
## V1 Out of scope
การรับและจ่ายเงินและการส่งเอกสาร
## External actors / systems
อาจารย์ / TA / ฝ่ายธุรการ
## Open questions / To validate
การให้ TA ตรวจและกรอกแบบร่างผ่านระบบก่อนพิมพ์เอกสาร จะช่วยลดการตีกลับเอกสารได้จริงหรือไม่
